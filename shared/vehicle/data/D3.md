# Argonne D3: chassis-dynamometer tests as a dev/exam set and a RoadSim twin test

Built 13 Nov 2026. Scripts: `data/scripts/d3_fetch.py` (download), `d3_index.py` (parse), `d3_specs.py` (twins),
`d3_splits.py` (frozen split), `checks/check_d3.py` (twin test). Loader: `realdata/d3.py`.

```python
import sys; sys.path.insert(0, 'shared/vehicle')
from realdata.d3 import d3_index, load_d3, d3_split, d3_specs
idx = d3_index(split='dev', category='hybrid')     # one row per test
meta, arr = load_d3('D3_62201031', tenhz=True)      # 1 Hz contract arrays + *_10hz originals
```

**Rule:** calibration may fit only on `dev` vehicles. `exam` vehicles are for the final report only.

## 1. Source and terms

Argonne National Laboratory, Downloadable Dynamometer Database (D3), anl.gov/taps/downloadable-dynamometer-database.
Files come from the public Box folder linked on each vehicle page (`d3_fetch.py`; anl.gov itself answers scripts
with HTTP 403, so the folder table was read once in a browser). Terms: use with attribution. Every output that uses
these data must carry:

> This data is from the Downloadable Dynamometer Database and was generated at the Advanced Mobility Technology
> Laboratory (AMTL) at Argonne National Laboratory under the funding and guidance of the U.S. Department of Energy (DOE).

Raw files stay in `data/raw/d3/` (git-ignored). `data/proc/d3/tests/` (the resampled arrays) is git-ignored too;
`index.parquet`, `channels.json`, `specs.json` and `splits.json` are small derived tables.

## 2. What is in it

65 vehicles, 1,753 test files; 1,661 parse into a usable 1 Hz trace (`ok`). The 2020 Tesla Model 3 (905 files,
90 GB) was not downloaded and is not in the split.

| category | dev vehicles / tests | exam vehicles / tests |
|---|---|---|
| conventional | 11 / 246 | 12 / 312 |
| hybrid | 6 / 112 | 7 / 168 |
| plug-in | 4 / 176 | 6 / 195 |
| electric | 8 / 210 | 7 / 145 |
| alternative (CNG, bi-fuel, fuel cell) | 3 / 92 | 1 / 5 |

Three file eras: `zip` ("All Data" zips, MY2009-2016, 779 ok tests, 10-12 channels), `txt` (Comprehensive/Extended
text files, MY2013-2022, 790), `tdms` (NI TDMS, MY2017-2023, 92). Ambient class of the ok tests: 1,107 at test-cell
temperature (std, 20-30 C), 269 cold (< 5 C, mostly -7 C, some -18 C), 284 hot (>= 30 C, mostly 35 C with 850 W/m2
lamps). Recognised schedules: UDDS 549, HWFET 235, US06 224, SC03 46, WLTC 25, NEDC 11, LA92/NYCC a few, multi-cycle
sequences (UDDS+HWFET+US06 42, ...); the rest are steady states, WOTs, grades, pedal maps, passing and charging.

## 3. Channels (1 Hz contract arrays; the 10 Hz originals are kept as `*_10hz`)

`data/proc/d3/channels.json` lists, per vehicle and era, which raw channel fed each signal. Signals and how many ok
tests have them:

| signal | meaning | tests |

| `fuel_rate` g/s | direct mass flow (688 tests), else volume flow x test-fuel density (1,008 with a volume meter), else the emissions bench's modal carbon balance (815 have it); `fuel_source` says which was used | 1,282 with fuel |
| `engine_rpm` | engine speed | 1,215 |
| `batt_voltage`, `batt_current`, `batt_power`, `soc` | high-voltage battery (+ = discharge) | 1,003 / 857 (`soc`) |
| `T_coolant`, `T_oil`, `T_trans_oil`, `T_cabin`, `T_batt` | temperatures | 912 / 1,209 / ... / 825 / 440 |
| `P_heater`, `P_ac`, `P_batt_heater`, `P_dcdc` | electric heater, A/C compressor, pack heater, 12 V DC/DC power | 128 / 272 / 79 / 865 |
| `T_amb`, `rho_air`, `solar` | cell temperature, air density, solar lamps (from notes or a solar sensor) | all |

## 4. Cleaning (`d3_index.py`, `checks/check_d3.py`)

- Resampled to 1 Hz on the facility clock. The time column is the one that advances (2020 Bolt 62009058 carries a
  constant `Time[s]` next to the facility clock; fixed 14 Nov 2026).
- Fuel: measured flow first, modal carbon balance only when nothing else exists; both totals are kept
  (`fuel_g_direct`, `fuel_g_modal`). Legacy-era (zip) fuel is mostly modal and scatters 20-30 % against EPA labels:
  weight it low.
- Battery current sign checked against tractive power during accelerations and flipped where needed
  (`batt_sign_flipped`).
- Schedule recognition: every standard schedule (UDDS, HWFET, US06, SC03, LA92, NYCC, NEDC, WLTC, JP10-15) is matched to
  the dyno speed by RMS; `cycle`, `cycle_seq` and `cycle_coverage` (share of the test's driving matched) per test.
- Start class from the initial coolant / oil temperature (or the notes); ambient class from the cell temperature.
- The twin check (`check_d3.py`) adds: only standard schedules with >= 60 % coverage, no grade, >= 1 km; key-off soaks
  (>= 300 s at rest with the engine stopped) cool every thermal state and restart from the logged temperatures;
  unmetered idle gaps between bags (engine idling, fuel record exactly 0, >= 60 s) are excluded on both sides; SC03
  x3-4 tests run each phase with its own HVAC setting; conventional fuel errors are over the recognised phases only
  (coast-downs after a HWFET are dropped); hybrids hold their logged start SOC, charge-sustaining plug-in tests their
  logged SOC; the HEV headline corrects fuel by net battery energy (SAE J1711-style, 0.33 x 0.90).

## 5. Split (`data/proc/d3/splits.json`, sha256 c628d0860a42155f..., frozen 13 Nov 2026)

By vehicle, stratified by category and era, seed 20261113, decided from the file listing only. Same-generation
siblings stay together (2012/2013 Volt, 2012/2013 Prius Plug-in, 2012 Leaf / 2013 Leaf SV, 2017/2019 Bolt, C-Max /
Fusion Energi). Pinned to dev as the only examples of their kind: 2021 Sonata Hybrid (modern P2), 2015 Accord Hybrid
(i-MMD), 2010 Prius (Toyota power-split), 2017 Prius Prime (plug-in with full channels), 2018 Camry XLE (the A25A map's
engine). Dev: 32 vehicles; exam: 33. Calibration fits only on dev; exam is computed once for a final report.

## 6. Twin specs (`d3_specs.py` -> `data/proc/d3/specs.json`)

Hardware from `data/d3_facts.json` (engine size and power, transmission, machines, pack) checked against
fueleconomy.gov and the EPA test-car table for the conventional dev cars (agent 1); road load from the D3 dyno targets
(A/B/C) or the matched EPA test-car row; test weight from D3. Rules added in the v2 calibration (14 Nov 2026): plug-in
pack power min(traction machines / 0.9, 9 C); a series hybrid's EPA N/V is the engine's and is used for the motor
only if it gives 140-260 km/h at 14,000 rpm; P0/P1 mild hybrids (Insight, S400h, CR-Z, Civic Hybrid, Malibu eAssist)
run as P2 machines with `engine_on_moving`. The Ford Energis keep electric (PTC) cabin heat: their -7 C charge-depleting
tests need it.

## 7. What is missing or unreliable

- 2020 Tesla Model 3: not downloaded (90 GB).
- 92 files do not parse into a drive trace: 34 (2020 Bolt) and 45 (2019 Leaf ePlus) are DC fast-charging logs with no
  dyno speed; 13 legacy zip members of the 2012 Volt and the 2012/2013 Prius Plug-in have no time or speed channel.
- No battery channel: 2012 Leaf (all tests), the 2020 Bolt test 62009058 (power-analyser columns unnamed). Battery
  power reads ~0 on the 2010 Insight and S400h (legacy): their HEV correction is unusable.
- 2020 Bolt: on some hot tests the logged heater/A/C channels and battery energy disagree with the drive (twin errors of
  -80 %); its logged heater power at -7 C (0.6-1.0 kWh per test) looks like part of the heating only.
- Logged coolant held at one value for whole tests on some cars (2018 Accord LX, 2017 Prius Prime): those temperatures
  are not used as starts when they contradict a cold start.
- Legacy-era fuel (zip) is a modal carbon balance: +-20-30 % against EPA labels.
- 9 duplicate test ids in the index (the same test in two folders).
