# RoadSim physics v2, work package B1: powertrain and hybrid control

Status: built 13 Nov 2026, not calibrated. Every option below is off by default, so RoadSim still reproduces physics
v1 exactly (`checks/fingerprint.py check`: 171 runs match). The intended v2 values are in the preset
`roadsim-physics-v2-b1` (`roadsim/options.py`). The calibration pass fits the numbers on dev data only.

```python
simulate(spec, trip, options='roadsim-physics-v2-b1')                 # everything in this note
simulate(spec, trip, options={'series_direct_drive': True})           # one feature
generate_vehicles(400, seed=1, donor_model='v2')                       # generator bodies
```

Files: `powertrain.py` (start energy, P2 converter, e:HEV lock-up), `strategies.py` (drivability and production
rules), `dp.py` (DP with on/off timers), `generator.py` + `data/generator_donors_v2.json` +
`tools/build_generator_donors_v2.py` (donors), `components.py` (`TorqueConverter.solve_vec`). No change to `sim.py`.

## 2. P2 hybrids: torque converter, starts, drivability (gap 1: city FTP 8-31 % too good)

**Torque converter.** P2 automatics with a converter (F-150 PowerBoost 10R80 MHT, Tacoma i-FORCE MAX 8AT) have engine,
K0 clutch and motor upstream of the converter. With `p2_torque_converter`, a P2 vehicle whose `Vehicle.tc` exists
(transmission type AT; set `transmission.torque_converter: false` to opt out) runs traction torque through the
K-factor model (Kotwicki, SAE 820393; Hrovat & Tobler, SAE 850461) while the converter is open:

    turbine (w_t, T_t) -> SR from w_t^2/T_t = SR^2 K(SR)^2 / TR(SR),  T_p = T_t / TR,  w_p = w_t / SR
    loss P_tc = T_p w_p - T_t w_t  (booked as transmission loss)

Engine and motor then run at the pump speed w_p (the engine slip-launches at its minimum loaded speed if w_p is lower).
Regenerative and coasting torque pass locked. The converter is open in first gear below 1.4 × the lock-up speed, in any
gear below it, and in the lowest `p2_tc_open_gears` gears (the same rule as the conventional AT model by default).
P2 vehicles with a dual-clutch box (Hyundai/Kia TMED) are unaffected.

**Engine-start energy.** v1 charged 1.5 s of warm idle fuel per start and nothing else. With `hybrid_start_energy`
a start also costs (per start, booked in the step it happens):

    E_eng  = 0.5 J w_s^2 (1 - (w_spin/w_s)^2) + |T_ct(w_s/2)| (w_s/2) t_crank      into the engine -> engine loss
    E_slip = k0 0.5 J w_s^2                                                     P2 K0 clutch slip -> transmission loss
    E_el   = (E_eng + E_slip) / eta_crank                                          from the battery; motor loss = E_el - E_eng - E_slip

J is the engine + input inertia RoadSim already uses (0.08 + 0.06 V_d kg m², Gillespie 1992 practice), T_ct the
motoring (closed-throttle) torque of the ALPHA map. w_s is `start_crank_rpm` for series and power-split hybrids (the
generator / MG1 spins the engine up; w_spin = the unfuelled speed of a power-split engine at road speed) and the shaft
speed for P2 (the engine must be synchronised before K0 closes). When the motor turns a stationary engine through a
slipping clutch while itself held at speed, the clutch dissipates as much energy as the engine gains (k0 = 1; standard
rigid-body clutch engagement result). Hyundai-type P2s that start with a belt starter-generator have k0 near 0
(set `engine.k0_slip_frac` in the spec). If the battery cannot supply E_el on top of the candidate's own power, the
motor supplies what it can and the engine fires early and spins itself up on fuel (`start_self_eta` 0.25, no slip
for that share), so a start is never infeasible. The start fuel (`start_fuel_idle_s`) stays as in v1. Values:
J = 0.2 kg m² for a 2 L engine gives E_el ≈ 3 kJ for a power-split start and 8-25 kJ for a P2 start at 1500-3000 rpm.

**Drivability.** `hybrid_min_on_s` / `hybrid_min_off_s` replace the per-strategy 4 s / 2 s (ECMS, A-ECMS, MPC,
PHEV, rule strategies); `hybrid_stay_on_P_frac` keeps a running engine on while the driver asks for more than 15 % of
engine power (no pull-out on a tip-in); `start_penalty_J` adds a virtual cost to every start in the cost-based
strategies (ECMS family, MPC, DP). These are drivability calibrations, chosen by judgement (8 s on, 3 s off, 20 kJ
≈ 0.47 g of fuel ≈ 3 s of idle); Sciarretta & Guzzella (IEEE Control Systems 27(2), 2007) discuss start penalties in
ECMS. Braking still turns the engine off within a run (RoadSim brakes with the engine unfuelled).

## 3. Honda e:HEV / i-MMD direct drive (gap 2: HWFET −9 %, US06 −10 %)

With `series_direct_drive`, a series hybrid can lock the engine to the wheels (Honda i-MMD "engine drive" mode;
Higuchi et al., SAE 2013-01-1476). Inside the window 70-140 km/h the strategies are offered every engine-on power P
twice: through the generator (series) and through the clutch (encoded as ctrl = -P). In lock-up

    w_e = v[km/h] · 20 rpm/(km/h) · pi/30,   T_e = P / w_e,   R = w_e / w_wheel
    traction motor: T_wheel,m = T_wheel - T_e R eta_dd   (assist when > 0, charging when < 0)
    generator turns unloaded (freewheel loss only); loss = T_e w_e (1 - eta_dd) + final-drive loss of the motor path

Candidates outside the window, below the engine's minimum loaded speed or above its full-load torque are infeasible.
ECMS-type strategies pick the mode by cost; the rule strategies (power follower, thermostat) try the lock-up first.
20 rpm per km/h is an estimate (engine near 2000 rpm at 100 km/h in i-MMD lock-up); η_dd = 0.96 for two gear meshes
and the final drive.

## 4. Toyota-type power-split production rules (gap 3: engine on 35 % vs 55 % in VED, fuel 0.80× logged)

With `powersplit_calibration` on a power-split vehicle (HEV, and PHEV outside charge depletion), the engine is forced on

- above 72 km/h whenever the driver asks for positive power (VED observation in HANDOFF.md; THS MG1 speed limits);
- while the coolant is below 40 °C, also at stops (warm-up);
- for the first 40 s of running after a start below 35 °C coolant (catalyst light-off);
- for a heater request when the cabin is heated by the engine: heat demand above 1000 W starts the engine below 45 °C
  coolant and keeps it on until 70 °C (hysteresis).

The start penalty (section 2) applies too. The rules sit on top of every power-split strategy (`powersplit_rule`, ECMS,
A-ECMS, MPC); DP keeps its v1 rules (a warm engine). The thresholds are public descriptions of THS behaviour, rounded,
and are the first things to calibrate on VED dev trips.

## 5. PHEV charge-depleting rules (gap 4)

With `phev_cd_rules`, in charge-depleting mode:

- **power-split PHEVs (blended type, small MG2: Prius Plug-in, Prius Prime, Ford Energi)** bring the engine in when the
  wheel power exceeds 0.9 × MG2 power or above 135 km/h (Prius Prime EV top speed);
- **series PHEVs (EREV, Volt-type)** stay electric unless the demand is infeasible;
- the engine starts for heat only when the cabin is heated by the engine (heater rule of section 4), or, with an electric
  heater, below `phev_heat_engine_below_C` (Volt-type engine-assisted heating; None = never). The electric heater
  itself is work package B2's;
- once started, the engine runs the minimum on time.

Charge-sustaining mode is unchanged (A-ECMS, with the section 4 rules for power-split PHEVs).

## 6. Generated bodies (gap 5: generated hybrids ~20 % less efficient; vans slow)

`generate_vehicles(..., donor_model='v2')` (default 'v1'):

- **hybrids** draw their body from real full-hybrid test records of the class (Camry/Accord/Sonata/Prius/RAV4/
  Escape/Highlander/... hybrids, F-150/Maverick/Tacoma hybrids), plug-ins from plug-in records (falling back to the
  hybrids below 10 records). A hybrid record's rated power is its engine's, so the engine gets that power and the system
  power is engine / U(0.65, 0.85). Plug-in records already carry the pack mass (no +8 %);
- **conventional and other gasoline bodies** exclude the hybrid and plug-in records (a conventional "Prius" with a
  72 kW engine was in v1);
- **vans** draw a minivan body (Pacifica, Sienna, Odyssey, Carnival) with probability 0.6 (US sales: ~0.4 M minivans
  vs ~0.3 M full-size vans per year, many of them above 8,500 lb and not in the list), else any van.

Records are identified by model name only, never by a test result. `tools/build_generator_donors_v2.py` rebuilds the
index file from the EPA test-car lists (MY2018, 2022-24) by matching rows to `generator_calib.json`; all 1,000+ rows
matched.

## 7. DP with minimum on/off times (gap 6)

With `dp_min_on_off`, `dp.dp_solve_timed` adds the time in the current engine mode to the DP state (Bellman recursion
as in Sundström & Guzzella, dpm, 2009): state = (on, τ = 1..n_on) or (off, τ = 1..n_off) × SOC grid. The engine may stop
only at τ = n_on and start only at τ = n_off, except in a step with no feasible candidate in the current mode (braking,
stops, demand beyond EV), as in the forward strategies. A start costs the start fuel + `start_penalty_J`, and with
`hybrid_start_energy` its cranking energy moves the SOC (a second stage table with the start step's battery power).
The closed-loop forward policy reads the same timer state. Cost: 11 timer states for 8 s / 3 s; a UDDS solve takes
about 2 s instead of 0.7 s.

schedule needs the PowerBoost data. The same observation suggests the conventional AT model locks too early (LIMITS item
1), which is outside B1.

## 11. Still missing

- The engine is unfuelled whenever RoadSim brakes, so the catalyst hold and the minimum on time end at the first
  braking step (a `sim.py` change; not done to keep B1 out of the main loop).
- The start energy is spread over one 1 s step; the sub-second dynamics are work package B3's 10 Hz mode.
- No DP for the production rules (warm-up, speed threshold); DP still assumes a warm engine.
- Power-split full-throttle launch is limited by the MG2 torque default (P_max / (0.3 w_max)) and battery power; real
  THS vehicles accelerate ~20 % faster. Generated hybrid hardware sizing and the rule-strategy mix are the rest of the
  generator's hybrid gap.
- No per-vehicle start device in the EPA specs (Hyundai TMED: belt starter-generator → `engine.k0_slip_frac: 0`).
- The D3 hybrids and PHEVs were not downloaded yet; confirm the i-MMD lock-up window and engine speed, the Sonata's
  start/K0 behaviour and the Prius engine-on rules on them before calibrating.
