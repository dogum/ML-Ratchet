# Example data

`*.hdf5` here: 32 s, 4 kHz GWOSC files for GW150914, GW151012, GW151226 and GW170104 (H1 and L1), from the GWOSC event
tutorial. License: CC BY 4.0, LIGO Scientific Collaboration and Virgo Collaboration.

GW170817 is too large to bundle (about 60 MB per detector). Download the two cleaned 2048 s files into this folder:

    https://dcc.ligo.org/public/0146/P1700349/001/H-H1_LOSC_CLN_4_V1-1187007040-2048.hdf5
    https://dcc.ligo.org/public/0146/P1700349/001/L-L1_LOSC_CLN_4_V1-1187007040-2048.hdf5

The raw Livingston file with the famous glitch (used for the gating test) is
`https://dcc.ligo.org/public/0146/P1700337/001/L-L1_LOSC_C00_4_V1-1187006834-4096.hdf5` (125 MB).
md5 checksums are listed on those DCC pages.
