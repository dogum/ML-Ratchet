QuakeNet v2

Several seismometers, one earthquake. Each station's record is read by QuakeNet v1.2. A small graph network, with stations as nodes and station pairs as edges, combines the readings and the P-wave arrival times into an epicentre, depth, magnitude and origin time, each with an error bar. It learned only from simulated earthquakes laid into real station noise. It was graded once on real USGS-located earthquakes.

What earned its place

Twin test · dev events only

Real records against their simulated twins

Each of the 40 dev earthquakes was re-simulated from its USGS moment tensor at the same stations, in real noise from those stations, and read the same way. Where the twin reads right and the real record does not, the simulator is missing something.
