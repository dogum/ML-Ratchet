FlowCast

Daily river flow for a basin that has never had a gauge. A small network read only weather and a map's worth of basin facts, learned from a hydrology simulator, and was then graded once on 619 real US rivers it had never seen.

Move a slider and the network reruns on the same two years. This shows what it learned from the simulator: wetter weather, warmer winters, steeper slopes or a big reservoir upstream. It is a what-if on one basin, not a forecast.

Flood peaks

Annual instantaneous USGS peaks vs annual maximum daily flow × 1.38 (B's dev ratio of instantaneous to daily peaks), median over basins of the per-basin median error. Cells are absolute error / bias, in %.

With a gauge: nowcast mode

An optional variant that also reads the basin's own observed flow up to 1, 3 or 7 days before each day (gauged protocol), scored once on the same exam. Weather of the target days is known (a hindcast).

Ratchet

How it got here

A rung is kept only if it beats the incumbent by more than 0.01 median NSE on a frozen set of simulated basins and loses no more than 5 % median NSE on the 52 real dev basins (water years 2001–2014, never part of the exam). When the physics changed, the frozen set was rebuilt and both models scored on it.

    Use it

    The release is numpy-only: flowcast-v1.0.zip with flowcast.py, the weights, demo.py on three exam basins, pipeline.py, the model card and every training script.

    import flowcast as fc
m = fc.FlowCast()
out = m.predict(forcing_df, attrs, start='1995-10-01', end='1996-09-30')
out[['Q', 'q05', 'q50', 'q95']]          # mm/day, and Q_m3s
