# StormNet offline lab

Open `index.html` in a browser. It contains the released readout, the four real exam excerpts, embedded fonts and the dev twin figure. Select a recording, move the issue hour, or change the most recent southward field. The network and the two-state baseline rerun locally.

The site uses the same numerical and UI source in `site/src/instruments/stormnet/`. Rebuild the packs with `python web/export_instrument.py` from the model directory, then run `node web/build_lab.mjs` with the site's npm dependencies installed. The Kyoto data-use conditions and credits appear in the page and in the examples README.
