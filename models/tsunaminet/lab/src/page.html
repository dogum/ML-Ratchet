Lab

Make a tsunami, then let the network read it

Set a source on the unit sources around the selected event's epicentre. The page sums the Green's functions at the same input buoys (only the 9 × 2 unit sources around the epicentre), adds 0.2 cm of Gaussian noise plus whatever you set, keeps that event's real data gaps, and runs the network on it. Then change the noise or drop a buoy and see how the posterior widens.
