# Data licence: CC BY-SA 4.0 (Building Data Genome 2)

The page in this folder, `index.html`, embeds data derived from the Building Data Genome 2 dataset (BDG2): Miller,
C., et al. (2020), "The Building Data Genome Project 2, energy meter data from the ASHRAE Great Energy Predictor III
competition", Scientific Data 7, 368, https://doi.org/10.1038/s41597-020-00712-x; data at
https://github.com/buds-lab/building-data-genome-project-2. Licensed CC BY-SA 4.0
(https://creativecommons.org/licenses/by-sa/4.0/).

Changes: the hourly 2017 site weather of five BDG2 sites (Hog, Bobcat, Bear, Bull, Fox), cleaned by BuildingData
(UTC, gaps interpolated), was cut to one winter and one summer week, rounded to 0.1 °C, and used to simulate twins of
three RECS 2020 respondents in BuildingSim; the page holds that weather, the simulated runs and the twins' hourly
house maps. You may share and adapt the embedded data under the same licence, with this credit.

The page also embeds summaries of WPuQ heat-pump data (Schlemminger et al. 2022, CC BY 4.0) and RECS 2020 respondent
characteristics (EIA, public domain). This licence covers the data only; the page's code and the rest of this
repository are MIT.
