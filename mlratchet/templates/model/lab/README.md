# Lab (optional)

An interactive page for this model: `lab/index.html`, self-contained, ideally with the network running in the
browser (a JS port of `__ID__.py`, checked against Python on a few examples), a real-data explorer, and a small
"lab" with sliders that change the input. Put page sources in `lab/src/`.

The website publishes `lab/index.html` at `/models/__ID__/lab/`. Keep it under ~8 MB and load nothing from
hosts other than well-known CDNs and Google Fonts.
